Бізнес-логіка лише на сервері (ADR-0003), у PL/SQL:

- автокоди/номери `000000001…` без перевикористання, ручний код 1–9 символів;
- помітка на видалення замість фізичного видалення, неактивні елементи не
  пропонуються у нових посиланнях;
- `amount = quantity × price` (scale 2), `totalAmount = Σ amount`, контроль
  дробової кількості за одиницею виміру;
- проведення/скасування/повторне проведення з атомарною заміною рухів,
  заборона від'ємних залишків і переплати постачальнику;
- проведений документ доступний лише для читання; «Скопіювати (F9)» створює чернетку;
- неблокувальні попередження (ціна нижча за собівартість, надходження понад замовлення тощо)
  показуються після «Документ проведено.»;
- ролі APEX: Адміністратор, Менеджер з продажу, Закупівельник, Комірник, Касир — панель функцій

  `sys_main_menu_section` / `sys_metadata_object`.

## Інтерфейс

Оформлення в стилі «Такси» 1С 8.3: панель розділів (Головне, Продажі, Закупівлі, Склад,
Ціноутворення, Фінанси, НСІ), панель функцій розділу, вкладки відкритих форм, форми з

```

  .env              згенеровані локальні паролі (не комітити)

  install.sql       повне встановлення схеми
```

## Запуск

```bash
colima start
cd infra && docker compose up -d
```

Застосунок: http://localhost:8181/ords/r/trade/trade/home
Користувач `DEVELOPER` (Адміністратор), пароль — `TRADE_APEX_USER_PWD` у `infra/.env`.
Ролеві користувачі `SALES1` (продажі), `BUYER1` (закупівлі), `STORE1` (склад) — паролі
`SALES1_PWD` / `BUYER1_PWD` / `STORE1_PWD` у `infra/.env`. Касир `CASH1` створюється
`infra/apex_users.sh`, якщо в `infra/.env` додати `CASH1_PWD`.
APEX-адміністрування: http://localhost:8181/ords/apex (workspace `TRADE`).

SQLcl-підключення збережені як `trade-local` (схема TRADE) і `trade-sys` (SYSDBA).

### Тема «1C-Taxi» (Theme Roller)

Оформлення в стилі 1С 8.3 «Такси» — це стиль теми **1C-Taxi** Universal Theme (на основі Iris),
поточний для застосунку. Власний CSS лежить у полі *Custom CSS* Theme Roller
(`themeRollerAttributes.jsonConfig`), скомпільований стиль — файл теми `1c-taxi.css`.
Окремого CSS-файлу в застосунку немає.

Джерело в репозиторії — `apex/theme-src/1c-taxi-custom.css`. Після змін:

```bash
python3 apex/gen/build_theme_style.py
```

далі `apex validate` / `apex import` як зазвичай. Якщо CSS змінили в Theme Roller (Save),
перенесіть його назад у `1c-taxi-custom.css`, інакше наступний імпорт його перезапише.
