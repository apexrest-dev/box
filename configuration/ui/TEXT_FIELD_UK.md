# TextField — звичайний текст

## Призначення й шаблон

Стандартний однорядковий текст без додаткових кнопок або піктограм:

```text
Номер: [00ФР-000205                         ]
```

```java
FormField<String> number = FormField.text("Номер", textOptions);
```

Спільна оболонка `FormField<T>` відповідає за підпис, обов'язковість, помилку й read-only. Усередині використовується стандартний JavaFX `TextField`.

## Вигляд і формат

- підпис стандартно ліворуч і входить у виділену ширину поля;
- редактор розтягується в межах поля;
- звичайний фон нейтральний, без жовтого кольору;
- read-only дозволяє фокус, виділення й копіювання, але не редагування;
- `disabled` не використовується замість read-only без потреби;
- максимальна довжина береться з паспорта;
- placeholder не замінює постійний підпис.

## Миша, клавіатура й commit

- подвійний клік виділяє весь текст;
- стандартні `Shift+Home/End`, `Ctrl+A/X/C/V`, `Delete`, `Backspace` підтримуються;
- `Enter`, `Tab` або перехід фокусу підтверджують текст;
- `Escape` відновлює попереднє підтверджене значення;
- повне видалення й перехід фокусу підтверджують порожній рядок або `null` згідно з паспортом;
- UI не перевіряє бізнес-унікальність і не надсилає запит після кожного символу.

## Контекстне меню

Використовується `STANDARD_EDITOR_CONTEXT_MENU_UK.md`. `Вибрати` й `Відкрити` видимі, але заблоковані. `Новий` відсутній.

## Таблиця

У display-режимі клітинка показує текст і використовує меню таблиці. В edit-режимі застосовується ця повна поведінка редактора; його меню не передається таблиці.

## Приклад паспорта

```text
number  string(max=20, blank=false)
comment string(max=1000, multiline=true)
```

Для багаторядкового значення використовується та сама семантика у `TextArea`, але висота й перенесення задаються паспортом.

## Обов'язкові тести

- довжина, порожнє значення й Unicode;
- подвійний клік і ручне виділення;
- commit/escape;
- read-only copy;
- контекстне меню;
- display/edit у таблиці;
- серверна помилка поля.
