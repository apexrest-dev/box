# DateField і DateTimeField

## Типи й шаблон

```text
DateField      — дата
DateTimeField  — дата і час
```

```text
Дата: [31.07.2026                    ][Календар]
Дата: [31.07.2026 00:20:00           ][Календар]
```

## Формати

```text
date               -> dd.MM.yyyy
datetime(minutes)  -> dd.MM.yyyy HH:mm
datetime(seconds)  -> dd.MM.yyyy HH:mm:ss
```

`DateField` працює з `LocalDate`. `DateTimeField` показує локальне представлення робочої часової зони, а API/сервер зберігають однозначний час згідно з загальними правилами UTC.
Технічний ISO-формат на кшталт `2026-07-31T21:20:15Z` у звичайних формах і списках користувачу не показується.

## Введення й календар

- користувач може повністю ввести значення в рядку;
- час `DateTimeField` редагується в тому самому рядку без окремих spinner-полів;
- `F4`, `Вибрати…` або кнопка `Календар` відкривають popup-календар;
- для `DateField` вибір замінює дату;
- для `DateTimeField` вибір дати зберігає наявний час;
- для порожнього `DateTimeField` вибір дати встановлює `00:00:00` або `00:00` відповідно до точності;
- некоректну дату/час не виправляти мовчки;
- порожній рядок підтверджує `null`;
- подвійний клік виділяє весь текст;
- `Escape` відновлює попереднє підтверджене значення.

## Контекстне меню

Використовується `STANDARD_EDITOR_CONTEXT_MENU_UK.md`:

- `Вибрати…` і `Відкрити…` відкривають календар на поточній даті;
- `Новий…` відсутній;
- вирізання, копіювання, вставлення, очищення й виділення працюють із текстовим представленням.

## Таблиця

У display-режимі показується лише форматована дата/дата-час і меню таблиці. В edit-режимі — повний календарний редактор із власним меню.

## Приклад паспорта

```text
documentDate date
occurredAt   datetime(seconds)
```

## Обов'язкові тести

- високосний рік і неіснуючі дати;
- межі часу;
- збереження часу при виборі іншої дати;
- порожнє значення;
- локальна зона/API-перетворення;
- commit/escape/read-only;
- display/edit у таблиці.
