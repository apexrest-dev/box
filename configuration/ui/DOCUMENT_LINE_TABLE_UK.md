# DocumentLineTable — таблична частина документа

## Статус

**Детальні правила ще не погоджені. Не реалізовувати компонент за припущеннями.**

Майбутнє обговорення має визначити:

- стандартну панель команд;
- повне контекстне меню;
- додавання, копіювання, редагування й видалення рядка;
- переміщення рядків;
- клавіші `Insert`, `Delete`, `F2`, `F4`, `F8`, `F9`, `Enter`, `Tab`, `Escape`;
- навігацію між клітинками;
- commit/cancel рядка;
- поведінку різних редакторів клітинок;
- підбір і масове заповнення;
- підвал і підсумки;
- налаштування колонок;
- права, статус документа й read-only;
- серверні команди зміни рядка;
- конфлікти версій та оновлення після відповіді сервера.

## Уже погоджено

- таблиця є частиною агрегату документа, але UI не змінює доменний об'єкт напряму;
- зміна передається у `ViewModel` типізованою командою, сервер повертає актуальний стан;
- для reference-клітинки display/edit поведінку визначає `REFERENCE_TABLE_CELL_UK.md`;
- у display mode діє майбутнє меню таблиці, в edit mode — меню активного редактора;
- `Insert` reference-редактора не повинен випадково перейти до таблиці.
- звичайне редагування одного рядка виконується безпосередньо в клітинках табличної частини; окрема форма рядка не відкривається;
- reference-реквізит рядка в режимі редагування використовує повний `ReferenceEditor` із вибором, очищенням, відкриттям картки та створенням за правами;
- кількість і ціна редагуються у відповідних числових клітинках, а сума показується як розрахункове значення;
- окрема форма допускається лише для спеціального складного сценарію, прямо визначеного паспортом, а не для стандартного рядка товару.
- після підтвердження значення `Enter` або `Tab` переводить редагування до наступної доступної для вводу колонки цього рядка;
- `Shift+Tab` переводить редагування до попередньої доступної колонки;
- після останньої колонки перехід продовжується з першої доступної колонки наступного рядка; за потреби стандартна таблична частина створює новий порожній рядок;
- `F9` копіює поточний рядок, вставляє копію після нього та відкриває її для редагування; новий рядок не успадковує ID;
- команда `Створити копію` з клавішею `F9` входить до контекстного меню табличної частини;
- сортування доступне для всіх колонок і враховує тип значення.

Після обговорення файл заповнюється за структурою `ELEMENT_TEMPLATE_UK.md`. До того часу поведінка таблиці не вважається визначеною.
