# NumericField — число, кількість, гроші й відсоток

## Типи й шаблон

```text
NumericField
├── IntegerField
├── DecimalField
├── QuantityField
├── MoneyField
└── PercentField
```

```text
Знижка: [                              0,00][Калькулятор]
```

Значення в Java — тільки `BigDecimal` або відповідний типізований value object. `double` і `float` заборонені.

## Precision і scale

Кожне поле явно задає:

- `precision` — загальну максимальну кількість цифр;
- `scale` — максимальну кількість цифр після коми.

```text
quantity  quantity(15,3)
price     money(19,2)
amount    money(19,2), readonly
discount  percent(5,2)
```

Клієнт не округлює й не обрізає надлишкові знаки мовчки. Правило округлення виконує сервер.

## Відображення й введення

- вирівнювання праворуч;
- формат показу: `1 234,50`;
- десятковий роздільник — кома, роздільник тисяч — пробіл;
- крапку можна прийняти при введенні й нормалізувати для показу;
- у режимі редагування роздільники тисяч можна не показувати;
- порожнє значення — `null`, а `0` — числовий нуль;
- подвійний клік виділяє весь текст;
- commit/cancel відповідає спільному життєвому циклу.

## Калькулятор

`F4`, `Вибрати…` або кнопка `Калькулятор` відкривають popup із поточним значенням. Він підтримує цифри, кому, `+`, `-`, `*`, `/`, `%`, `+/-`, `1/x`, `C`, `CE`, backspace та `OK`.

- усі операції виконуються через `BigDecimal`;
- `Enter` відповідає `OK`;
- `Escape` закриває popup без змін;
- `OK` переносить результат у редактор, але бізнес-підтвердження виконується звичайним commit поля;
- ділення на нуль показує локальну помилку;
- калькулятор не містить бізнес-формул.

## Контекстне меню

Використовується `STANDARD_EDITOR_CONTEXT_MENU_UK.md`:

- `Вибрати…` — калькулятор;
- `Відкрити…` — калькулятор із поточним значенням;
- `Новий…` відсутній;
- текстові операції працюють із текстом редактора.

## Таблиця

У display-режимі — лише праворуч вирівняний форматований текст і меню таблиці. В edit-режимі — повний `NumericField`, його калькулятор і контекстне меню.

## Обов'язкові тести

- precision/scale, знак, `null` і нуль;
- українське форматування та вставлення з крапкою;
- відмова від мовчазного округлення;
- калькулятор і ділення на нуль;
- commit/escape/read-only;
- display/edit у таблиці.
