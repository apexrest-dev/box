# ReferencePicker — повна форма вибору

## Призначення

Типізована форма списку, яка повертає одне посилання до `ReferenceField` або редактора клітинки.

```text
ReferencePicker<TRef>
├── пошук
├── фільтри
├── таблиця результатів
├── пагінація
└── Вибрати / Скасувати
```

## Відкриття

- кнопка `Вибрати` поля;
- `F4` активного `ReferenceField`;
- пункт `Показати всі` popup;
- `Вибрати…` контекстного меню.

Поточний текст передається як початковий пошук.

## Поведінка

- серверні пошук, фільтри, сортування й пагінація;
- сервер повертає лише доступні користувачу записи;
- подвійний клік або `Enter` підтверджують поточний рядок;
- окрема кнопка `Вибрати` робить те саме;
- `Escape`/`Скасувати` закривають форму без зміни поля;
- після підтвердження повертається типізований `Ref`, не доменна/JPA-сутність;
- форма може повторно використовувати `EntityTable` у selection mode;
- створення нового елемента не є прихованою логікою picker; воно доступне лише згідно з паспортом і capabilities.
- якщо цільовий довідник підтримує створення і сервер повернув право `create`, форма вибору показує кнопку `Створити`;
- `F8` та `Insert` у формі вибору виконують ту саму дію;
- після успішного створення новий елемент одразу повертається й вибирається в початковому полі;
- правило однаково діє для товарів, одиниць виміру, складів, контрагентів та інших довідників.

## Приклад

```java
ReferencePicker<CounterpartyRef> picker;
```

## Обов'язкові тести

- початковий запит;
- подвійний клік/Enter/Escape;
- пагінація й права;
- повернення правильного типізованого значення;
- відсутність зміни при cancel.
