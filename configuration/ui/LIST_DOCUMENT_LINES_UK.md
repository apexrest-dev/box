# Список рядків табличної частини документа

## Статус

Детальна специфікація ще доповнюватиметься. Уже погоджена базова поведінка:

- рядок редагується безпосередньо у клітинках без окремої форми;
- `Enter` і `Tab` виконують автообхід доступних для вводу колонок, `Shift+Tab` — зворотний обхід;
- після останньої колонки обхід переходить до наступного рядка або створює новий;
- `F9` і команда контекстного меню `Створити копію` копіюють поточний рядок без його ID;
- усі колонки підтримують типізоване сортування.
