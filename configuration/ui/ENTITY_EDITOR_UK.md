# EntityEditor — форма елемента або документа

## Призначення

Типізований каркас конкретної JavaFX-форми. Він не генерує поля й не описує бізнес-модель метаданими.

```text
EntityEditor
├── HEADER
├── CONTENT
└── FOOTER
```

Конкретна форма явно складається зі спільних компонентів і дотримується `FORM_LAYOUT_UK.md`.

## Спільна відповідальність

- завантаження й показ серверного стану;
- loading/error/dirty;
- захист від втрати непідтверджених змін;
- стандартний порядок фокусу;
- commit/cancel UI-редакторів;
- відображення доступних сервером дій;
- показ помилок поля й загальної помилки;
- навігація та закриття форми.

## Ctrl+Enter: основна команда із закриттям

`Ctrl+Enter` викликає основну підтверджувальну команду поточної форми:

- для елемента довідника — `Записати і закрити`;
- для документа — `Провести і закрити`;
- для іншої форми — лише явно визначену паспортом команду із закриттям.

Форма закривається тільки після успішної відповіді сервера.

## Провести і закрити

У формі документа `Ctrl+Enter` виконує дію `Провести і закрити`:

1. активний редактор завершує введення;
2. форма перевіряє лише локальну коректність формату;
3. клієнт надсилає дозволену типізовану команду серверу;
4. сервер записує та проводить документ у погодженій транзакції;
5. форма закривається тільки після успішної відповіді сервера;
6. при помилці форма залишається відкритою, показує повідомлення й переводить фокус до помилкового поля, якщо сервер його указав.

Для довідника `Ctrl+Enter` виконує `Записати і закрити`, без проведення.
Активний popup або редактор, який використовує `Ctrl+Enter` за власним явно погодженим правилом, має пріоритет.

## Escape: закриття форми

- `Esc` закриває незмінену форму без додаткового запитання;
- якщо є незбережені зміни, показується вибір `Записати`, `Не записувати`, `Скасувати`;
- `Записати` закриває форму лише після успішної серверної відповіді;
- активний popup спочатку закриває себе й споживає `Esc`, не закриваючи всю форму.

Форма підтвердження незбережених змін має стандартну клавіатуру:

- початковий фокус завжди на `Записати`;
- `Tab` і `Shift+Tab` циклічно переводять фокус між кнопками;
- `Enter` або `Ctrl+Enter` виконує сфокусовану кнопку;
- `Esc` завжди відповідає кнопці `Скасувати`;
- заголовок і всі кнопки відображаються українською.

## Заборонено

- бізнес-формули;
- локальне визначення прав;
- проведення документа всередині View;
- прямий доступ до БД;
- універсальна зміна поля за його рядковою назвою;
- передавання JPA/domain-сутності до JavaFX.

```java
    // Явно створені типізовані поля й компонування.
}

final class GoodsReceiptEditorViewModel {
    // Стан форми, API-виклики й типізовані команди без бізнес-логіки.
}
```

## Обов'язкові тести

- loading/error/dirty;
- закриття з незбереженими змінами;
- права й read-only;
- commit/cancel активного редактора;
- серверна помилка поля;
- порядок фокусу;
- компонування на підтримуваних розмірах.
- `Ctrl+Enter`: commit, успішне проведення і закриття; помилка без закриття.
