# ReferenceField — посилання на елемент довідника

## Шаблон і вигляд

```text
Клієнт: [ Приватна особа                         ][▼][×][…]
```

Праворуч усередині спільної рамки редактора розташовані три маленькі службові кнопки без текстових написів:

- `▼` — вибрати зі списку;
- `×` — очистити значення;
- `…` — відкрити картку вибраного елемента.

За замовчуванням показуються всі три кнопки. Недоступна дія не приховується, а показується заблокованою. Кожна кнопка має український tooltip та accessibility-текст із повною назвою дії. Кнопки мають однакову компактну ширину, спільну висоту з редактором і не входять до окремого Tab-порядку. Текстова частина займає весь вільний простір. Повні слова `Вибрати`, `Очистити`, `Відкрити` використовуються в контекстному меню, але не на кнопках поля.

```java
ReferenceField<CounterpartyRef> clientField =
        new ReferenceField<>(lookup, navigator, capabilities);
```

Компонент зберігає типізоване посилання, а не лише текст:

```java
record CounterpartyRef(CounterpartyId id, String code, String displayName) {}
```

## Контекстний пошук

- введення тексту скидає підтверджений вибір і переходить у search mode;
- пошук запускається після паузи приблизно 250 мс і мінімальної кількості символів;
- сервер повертає обмежений список доступних результатів;
- застарілі асинхронні відповіді ігноруються;
- popup відкривається під полем, підтримує `Up/Down`, `Enter`, `Escape` і мишу;
- `Показати всі` відкриває `ReferencePicker` з поточним запитом;
- непідтверджений текст не є посиланням і не надсилається як ID.

## Кнопки й клавіатура

- `Вибрати` / `F4` — повна форма списку в режимі вибору;
- `Очистити` / `Shift+F4` — встановити `null`; кнопка заблокована для порожнього або read-only поля;
- `Відкрити` / `Ctrl+Shift+F4` — форма вибраного елемента;
- `Відкрити` заблокована без вибраного значення;
- подвійний клік у тексті виділяє все;
- повне видалення тексту й перехід фокусу підтверджують `null`;
- `Escape` до commit відновлює попереднє посилання.

## Контекстне меню

Використовується `STANDARD_EDITOR_CONTEXT_MENU_UK.md` із командою:

```text
Новий…                         F8, Insert
```

`Новий` відкриває форму нового елемента цільового довідника. Після успішного серверного збереження повернений `Ref` автоматично вибирається. Скасування залишає попереднє значення.

Якщо створення підтримується, але немає права, команда видима й заблокована. `F8`/`Insert` споживаються редактором і показують коротке немодальне пояснення. Якщо створення не підтримується паспортом, команда відсутня.

## Права

Capabilities щонайменше описують `canRead`, `canSelect`, `canOpen`, `canCreate`. Сервер фільтрує пошук, перевіряє відкриття/створення й залишається остаточним джерелом прав.

Read-only поле забороняє зміну, вибір і очищення, але може дозволяти `Відкрити` та копіювання, якщо є право читання.

## Контракти

```java
interface ReferenceLookup<T> {
    CompletionStage<List<T>> search(String query, int limit);
}

interface ReferenceNavigator<T> {
    void openPicker(String initialSearch, Consumer<T> onSelected);
    void openElement(T selected);
    void createElement(String initialText, Consumer<T> onCreated);
}
```

Компонент не знає URL, таблицю БД, конкретний API-клієнт чи бізнес-фільтри.

## Приклад паспорта

```text
client reference<Counterparty>, required, createAllowed=true
```

## Обов'язкові тести

- debounce і застаріла відповідь;
- вибір/непідтверджений текст/очищення/escape;
- три кнопки й клавіші;
- права read/select/open/create;
- створення й скасування нового елемента;
- popup і повна форма вибору;
- read-only.
