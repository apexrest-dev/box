# Стандартне контекстне меню редакторів

## Базовий порядок

Меню текстове, без піктограм:

```text
Вибрати…                       F4
Відкрити…                      Ctrl+Shift+F4
────────────────────────────────────────
Вирізати                       Ctrl+X
Копіювати                      Ctrl+C
Вставити                       Ctrl+V
Очистити                       Shift+F4
────────────────────────────────────────
Виділити все                   Ctrl+A
```

`ReferenceField` додає перед першим роздільником:

```text
Новий…                         F8, Insert
```

## Доступність

- `Вибрати` і `Відкрити` залишаються видимими; непідтримувані типом поля команди заблоковані;
- `Новий` існує лише для посилання, паспорт якого допускає створення цільового елемента;
- підтримувана, але заборонена правом команда `Новий` видима й заблокована;
- `Вирізати`, `Вставити`, `Очистити` недоступні в read-only;
- `Копіювати` й `Виділити все` доступні в read-only;
- `Очистити` встановлює `null`, а не нуль чи порожній об'єкт;
- натискання клавіші заблокованої команди споживається й не передається батьківському компоненту.

## Спільна текстова поведінка

- подвійний клік виділяє весь текст;

## Власник клавіатурної команди

Активний редактор перехоплює тільки команди, які належать його типу:

- `F4` — вибір посилання, калькулятор або календар;
- `F3` — негайний контекстний пошук посилання;
- `Insert` і `F8` — створення цільового елемента, якщо дія підтримується;
- `F2` — початок редагування reference-клітинки;
- `Delete` — стандартне видалення виділеного тексту під час редагування;
- `F9` — не команда поля; вона передається формі або списку для сценарію «копіювати як новий».
- ручне виділення працює як у текстовому редакторі;
- видалення всього виділеного тексту залишає порожній редактор;
- перехід на інше поле підтверджує очищення;
- `Escape` до підтвердження відновлює попереднє значення.
