# Карта об'єктів 1С:УТП / УТ 11 → Trade

Документ зіставляє типові об'єкти «1С:Управління торговельним підприємством» /
«1С:Управління торгівлею 11» з об'єктами Trade і фіксує дорожню карту.
Типова конфігурація містить сотні об'єктів; Trade реалізує їх ревізіями
вертикальними зрізами (паспорт → схема → проведення → форми → тести).

Позначки: ✅ реалізовано · 🟡 частково/спрощено · ⬜ заплановано.

## Рекомендований порядок

1. **r3 — оперативний цикл продажів і склад:** Замовлення клієнта з резервами,
   Повернення від клієнта/постачальнику, Інвентаризація (+ надлишки), групи номенклатури,
   штрихкоди, друк видаткової накладної, введення на підставі, ролі доступу.
2. **r4 — гроші й собівартість:** організації, договори, каси/банк, ПКО/ВКО,
   собівартість (середня зважена), звіт «Валовий прибуток».
3. **r5 — розширення:** валюти й курси, знижки, ціни постачальників, ордерна схема.

Кожна ревізія починається з паспортів у `configuration/objects/*/PASSPORT_UK.md`.
