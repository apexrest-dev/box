# Паспорт регістру відомостей «Ціни номенклатури»

## 0. Стан паспорта

- Статус: `PROPOSED` — реалізовано в r2 за дорученням користувача 2026-11-08
  («подивися, зроби»); потребує явного погодження для переведення в `AGREED`.
- Ревізія: `r2`.
- Розділ основного меню: `Звіти`.
- Залежності: `RefPriceType`, `RefProduct`; реєстратор `DocPriceSetting`.
- Аналог у 1С:УТ/УТП: РегистрСведений.ЦеныНоменклатуры (периодичний, підпорядкований реєстратору).

## БЛОК A. СТРУКТУРА

Таблиця `reg_product_price`, сторінка 150. Періодичний регістр відомостей.

| Поле | Роль | Тип |
|---|---|---|
| `period` | період | Date (seconds) |
| `recorder_type/id`, `line_number` | реєстратор | UNIQUE |
| `price_type_id` | вимір | `RefPriceType` |
| `product_id` | вимір | `RefProduct` |
| `price` | ресурс | Number(19,2) |

## БЛОК B. UI

Read-only звіт: «Діючі ціни» (зріз останніх на поточну дату) і «Історія» з переходом
до документа-реєстратора.

## БЛОК C. БІЗНЕС-ЛОГІКА

Зріз останніх: `trade_lines.get_price(priceType, product, date)` — запис із
максимальним `period <= date`. Записи формуються лише проведенням `DocPriceSetting`.
