# Паспорт звіту «Оборотність запасів»

## 0. Стан паспорта

- Статус: `PROPOSED` — підготовлено 2026-11-08, потребує явного погодження користувачем
  для переведення в `AGREED` (реалізовано за загальним дорученням користувача, APE-116).
- Ревізія: `r5`.
- Розділ меню (Taxi): `Склад`, `Продажі`, `Закупівлі`, `Головне` → «Звіти»; список «Звіти».
- Залежності: `RegStockCost` (кількість і вартість запасів, середня ковзна), `RegSales` (продажі й повернення),
  `RefProduct`, `RefProductGroup`, `RefWarehouse`, `RefOrganization`; звіт «Картка товару» (сторінка 450).
- Аналог у 1С:УТ 11: звіт «Оборачиваемость запасов» (Запасы → Отчеты по запасам): средний остаток,
  себестоимость продаж, коэффициент и период оборачиваемости в днях.
- Функції каталогу: `F-WH-24`.

## БЛОК B. ЛОГІКА (`trade_turnover`, db/45)

- Середній залишок — середнє залишків на кінець кожного дня періоду (n днів): рух дня d входить у (to − d + 1)
  з n денних залишків, тобто `avg = залишок на початок + Σ рух × (to − d + 1) / n`. Рахується окремо для кількості
  й вартості; адитивний, тому підсумки за групою / складом — сума середніх.
- Собівартість продажів — собівартість рядків `RegSales` за `RegStockCost` (реалізації, чеки ККМ); повернення від
  покупців зменшують продано й собівартість. Послуги (вид `SERVICE`) не входять.
- Коефіцієнт оборотності = собівартість продажів / середній залишок за вартістю (середній ≤ 0 — порожньо).
- Оборотність у днях = n / коефіцієнт = середній залишок × n / собівартість продажів (продажів немає — «немає
  продажів»). Довша за період — виділяється червоним. Також `qty_ratio` = продано / середній залишок кількості.
- Порядок: позиції із залишком без продажів, далі за спаданням днів (найповільніші зверху).
- `analysis` (конвеєрна) — дані; `turnover_html` — HTML з підсумком (середній залишок, собівартість продажів,
  коефіцієнт, дні, позицій, без продажів) і таблицею; товари — посилання на картку товару (сторінка 450:
  товар, склад рядка або відбору, період; лише в APEX-сесії).

## БЛОК D. ВІДХИЛЕННЯ ВІД 1С

| Рішення | Пояснення |
|---|---|
| Джерело залишку — `RegStockCost` | у ньому є кількість, вартість і організація (у `RegStockBalance` організації немає), тож відбір за організацією узгоджений для кількості й вартості |
| Денна точність | середній залишок рахується за залишками на кінець дня, не за моментами часу |
| Характеристики / серії | не деталізуються (звіт у розрізі товар × склад) |
| Нормативна оборотність | порівняння з нормативом і прогноз днів запасу — не реалізовано |
