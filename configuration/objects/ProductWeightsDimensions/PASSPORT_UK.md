# Паспорт «Ваги й габарити товарів» (реквізити `RefProduct` + звіт «Вага й об'єм документів»)

## 0. Стан паспорта

- Статус: `PROPOSED`. Підготовлено 2026-11-09, переводиться в `AGREED` лише після явного погодження користувачем
  (реалізовано за загальним дорученням користувача, APE-119).
- Ревізія: `r6`.
- Розділ меню (Taxi): реквізити — картка «Номенклатура» (сторінки 20/21); звіт — `Склад`, `Продажі`, `Закупівлі` → «Звіти».
- Залежності: `RefProduct` (r3 `weight_kg`), `RefUnitOfMeasure`, документи з товарами (реалізація, замовлення клієнта,
  рахунок на оплату, переміщення, надходження, замовлення постачальнику, повернення від клієнта й постачальнику,
  видатковий ордер на товари), `RefOrganization`, `RefWarehouse`, `RefCounterparty`.
- Аналог у 1С:УТ 11: реквізити номенклатури «Вес», «Объем», «Длина / Ширина / Высота» (вкладка «Хранение, габариты»),
  підсумок ваги й об'єму в документах продажу й переміщення («Вес / Объем» у підвалі), звіт для планування доставки.
- Функції каталогу: `F-WH-26`.

## БЛОК A. СТРУКТУРА

### Нові реквізити `ref_product` (db/48)

| Поле | Назва | Тип | Правила |
|---|---|---|---|
| `weight_kg` (r3) | Вага, кг | number(19,3) | вага базової одиниці виміру; ≥ 0 |
| `volume_m3` | Об'єм, м³ | number(19,6) | ≥ 0; якщо задано всі три габарити — розраховується `Д × Ш × В / 1 000 000` (ручне значення перезаписується) |
| `length_cm` | Довжина, см | number(19,1) | ≥ 0 |
| `width_cm` | Ширина, см | number(19,1) | ≥ 0 |
| `height_cm` | Висота, см | number(19,1) | ≥ 0 |

- Для послуг (`product_kind = SERVICE`) вага, об'єм і габарити очищаються тригером `ref_product_r6_biu`.
- Вага / об'єм одиниці в розрахунках (`v_cargo_product`): без значення в картці — з одиниці виміру: «кг» = 1 кг,
  «г» = 0,001 кг, «т» = 1000 кг; «л» = 0,001 м³, «м3» = 1 м³. У довідник не записується.

### Представлення й пакет

| Об'єкт | Призначення |
|---|---|
| `v_cargo_doc_line` | рядки товарів 9 видів документів (вид з `v_recorder`, id, № рядка, товар, кількість) |
| `v_cargo_product` | вага й об'єм одиниці з урахуванням одиниці виміру |
| `v_cargo_line` | вага й об'єм рядка = кількість × одиниця; ознаки «немає ваги / об'єму» (послуги — 0, не рахуються) |
| `v_cargo_doc_head` / `v_cargo_doc` | шапки (вид, напрям OUT / IN / MOVE / NONE, дата відвантаження, статус, організація, склад(и), контрагент, сторінка) + підсумки: рядків товарів, кількість, вага, об'єм, рядків без ваги / об'єму |
| `trade_cargo` | `unit_weight`, `unit_volume`, `volume_of`, `doc_weight`, `doc_volume`, `doc_missing`, `load_percent`, `to_num`, `summary_html`, `cargo_html` |

Дата відвантаження: дата документа; замовлення клієнта — «Дата відвантаження» (`shipment_date`), замовлення
постачальнику — «Очікувана дата». Рахунок на оплату — напрям `NONE`: підсумок показується у формі, у звіт
потрапляє лише за явним відбором виду (щоб не дублювати замовлення / реалізацію).

## БЛОК B. ЛОГІКА

- `summary_html(вид, id)` — рядок «Вага й об'єм для доставки: вага … кг · об'єм … м³ · рядків товарів · кількість»;
  якщо в рядках є товари без ваги / об'єму — попередження з переліком (до 10 товарів) і кількістю рядків.
- `cargo_html(з, по, напрям, вид, організація, склад, лише проведені, вантажопідйомність кг, об'єм м³)` — документи з
  товарами за датою відвантаження: дата, документ (посилання на форму), статус, контрагент, склад (переміщення —
  «звідки → куди»; відбір за складом — будь-який із двох), рядків товарів, вага, об'єм, рядки без даних,
  % завантаження за вагою / об'ємом (якщо задано місткість транспорту; > 100 % — червоним), підсумок, кількість рейсів
  при перевантаженні, попередження про неповний підсумок. Помилки параметрів (період, напрям, від'ємна місткість) —
  повідомленням у звіті.

## БЛОК C. UI

- Картка товару (21): «Вага, кг», «Об'єм, м³», «Довжина / Ширина / Висота, см» (з підказками); список (20) — колонки
  «Вага, кг», «Об'єм, м³».
- Форми документів 51, 111, 131, 261, 271, 281, 291, 321, 571 — регіон «Вага й об'єм» над підвалом (для записаного документа).
- Сторінка 720 «Вага й об'єм документів» (усі ролі): з / по (типово сьогодні … +7 днів), напрям, вид документів,
  організація, склад, статус (усі / лише проведені), вантажопідйомність, об'єм кузова; «Сформувати», «Друк».

## БЛОК D. ВІДХИЛЕННЯ ВІД 1С

| Рішення | Пояснення |
|---|---|
| Одиниці ваги й об'єму | фіксовані кг і м³ (габарити — см); у 1С одиниця ваги / об'єму обирається |
| Упаковки | вага й габарити — лише базової одиниці; ваги упаковок (`RegBarcode.unit_quantity`) не задаються |
| Вага брутто / нетто | одне значення ваги одиниці |
| ТТН, рейси, транспорт | довідника транспорту й документа «Завдання на перевезення» немає — місткість вводиться параметром звіту; ТТН — окрема задача доставки |
| Імпорт довідників | нові реквізити (об'єм, габарити) в майстер імпорту (APE-69) не додано |
| Друк накладної | вага / об'єм у друкованих формах не виводяться |
