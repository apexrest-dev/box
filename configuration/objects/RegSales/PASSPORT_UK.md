# Паспорт регістру оборотів «Продажі»

## 0. Стан паспорта

- Статус: `PROPOSED` — реалізовано в r2 за дорученням користувача 2026-11-08
  («подивися, зроби»); потребує явного погодження для переведення в `AGREED`.
- Ревізія: `r2`.
- Розділ основного меню: `Звіти`.
- Залежності: `RefCounterparty`, `RefWarehouse`, `RefProduct`; реєстратор `DocGoodsSale`.
- Аналог у 1С:УТ/УТП: РегистрНакопления.ВыручкаИСебестоимостьПродаж (без собівартості).

## БЛОК A. СТРУКТУРА

Таблиця `reg_sales_turnover`, сторінка 160. Оборотний регістр накопичення.

| Поле | Роль | Тип |
|---|---|---|
| `period`, `recorder_*`, `line_number` | системні | — |
| `counterparty_id`, `warehouse_id`, `product_id` | виміри | FK |
| `quantity`, `amount` | ресурси | Number(19,3) / Number(19,2) |

## БЛОК B. UI

Звіт з відбором за період: «За товарами» (кількість, сума, середня ціна),
«За покупцями», «Записи» з переходом до реалізації.

## БЛОК C. БІЗНЕС-ЛОГІКА

Записи формуються лише проведенням `DocGoodsSale`; прямий запис заборонений.
Собівартість і валовий прибуток — у наступній ревізії (див. дорожню карту).
