# Паспорт довідника «Комірки складів»

## 0. Стан паспорта

- Статус: `PROPOSED` — підготовлено 2026-11-08, потребує явного погодження користувачем
  для переведення в `AGREED` (реалізовано за загальним дорученням користувача, APE-65).
- Ревізія: `r5`.
- Розділ меню (Taxi): `Склад` → «НСІ»; `НСІ та адміністрування` → «Склади».
- Залежності: `RefWarehouse` (`useStorageBins`), `RegBinStock` (див. `RegGoodsOrderScheme`).
- Аналог у 1С:УТ 11: Справочник.СкладскиеЯчейки (спрощено: без областей / приміщень, типорозмірів
  і правил розміщення — `F-WH-14`, APE-282).
- Функції каталогу: `F-WH-11`.

## БЛОК A. СТРУКТУРА

### 1. Ідентичність і призначення

| Параметр | Значення |
|---|---|
| Українська назва | Комірки складів (елемент — «Комірка складу») |
| Технічне ім'я | `RefStorageBin` |
| Таблиця | `ref_storage_bin` |
| Сторінки APEX | 550 — список, 551 — картка (модальний діалог) |
| Права | перегляд — усі ролі; запис / помітка — «Роль: склад» |
| Вид видалення | `MARK_FOR_DELETION` (`trade_core.catalog_table` + `REF_STORAGE_BIN`) |

Місце адресного зберігання на складі (стелаж-ярус-місце). Використовується в рядках прибуткових
(розміщення) і видаткових (відбір) ордерів складів з ознакою «Адресне зберігання».

### 2. Поля

| Поле | Назва | Тип | Обов'язкове | Правила |
|---|---|---|---|---|
| `code` | Код | String(9) | так | автоматичний `ref_storage_bin_code_seq` |
| `warehouseId` | Склад | ref `RefWarehouse` | так | активний; не змінюється, якщо за коміркою є рухи (`STORAGE_BIN_IN_USE`) |
| `rack`, `tier`, `place` | Стелаж, ярус, місце | String(20) | ні | верхній регістр |
| `name` | Адреса | String(100) | так | порожня — `стелаж-ярус-місце` (без порожніх частин); без стелажа й адреси — `STORAGE_BIN_ADDRESS`; унікальна в межах складу (`ref_storage_bin_name_uk`) |
| `description` | Опис | String(1000) | ні | — |
| `state`, `version`, аудит | — | — | — | стандартні |

## БЛОК B. ЛОГІКА Й UI

- Тригер `ref_storage_bin_biu` → `trade_order_scheme.check_bin`; фізичне видалення заборонене.
- Список 550 (`v_storage_bin_list`): склад, адреса, стелаж / ярус / місце, кількість товарів і позицій у комірці.
- LOV `storage-bins-active` («Склад: адреса») — колонка «Комірка» в рядках ордерів;
  у шапці прибуткового ордера — комірки складу документа.
- Залишки по комірках — регістр `RegBinStock` (звіт 580, вкладка «Товари в комірках»).
