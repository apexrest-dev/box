# Паспорт регістру відомостей «Правила уцінки неліквідів»

## 0. Стан паспорта

- Статус: `PROPOSED` — підготовлено 2026-11-08, потребує явного погодження користувачем
  для переведення в `AGREED` (реалізовано за загальним дорученням користувача, APE-117).
- Ревізія: `r5`.
- Розділ меню (Taxi): `Ціноутворення` → «Знижки»; список «Звіти».
- Залежності: використовує звіт «Неліквіди й залежалі товари» (`SlowMovingStock`, пакет `trade_slow_stock`).
- Аналог у 1С:УТ 11: у типовій конфігурації немає окремого регістра — уцінку неліквідів роблять документом
  «Установка цен номенклатуры» за звітом; правила додано, щоб рекомендації були налаштовними.
- Функції каталогу: `F-WH-25`.

## БЛОК B. ЛОГІКА (`trade_slow_stock`, db/46)

- До позиції застосовується правило з найбільшим порогом, не більшим за кількість днів без продажу / руху.
- Найменший поріг — типове значення параметра «Днів» звіту (`default_days`; правил немає — 90).
- Позиція залежала, але першого порогу не досягнуто — «Контролювати» без уцінки.
- Серія з терміном, що спливає протягом N днів, — уцінка першого правила («Уцінити: спливає термін»).
- Для «Списати» рекомендована ціна не рахується.
