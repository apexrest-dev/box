# Паспорт документа «Встановлення цін номенклатури»

## 0. Стан паспорта

- Статус: `PROPOSED` — реалізовано в r2 за дорученням користувача 2026-11-08
  («подивися, зроби»); потребує явного погодження для переведення в `AGREED`.
- Ревізія: `r2`.
- Розділ основного меню: `Документи`.
- Залежності: `RefPriceType`, `RefProduct`, `RegProductPrice`.
- Аналог у 1С:УТ/УТП: Документ.УстановкаЦенНоменклатуры.

## БЛОК A. СТРУКТУРА

Таблиці `doc_price_setting` + `doc_price_setting_prices`, сторінки 100/101.

Шапка: `doc_number`, `occurred_at`, `price_type_id` (обов'язковий, активний), `doc_comment`, `status`.
Таблична частина «Ціни»: `line_number`, `product_id` (активний), `price >= 0`.

### Статуси й життєвий цикл

`DRAFT -> POSTED` командою Post, `POSTED -> DRAFT` командою Unpost. У `POSTED`
шапка й рядки read-only (тригер). Фізичне видалення проведеного документа
заборонене. «Скопіювати (F9)» створює нову чернетку без номера, аудиту й рухів.
Повторне проведення атомарно замінює набір записів реєстратора.

## БЛОК B. UI

Форми: список (IR, сторінка 100) і документ (сторінка 101). Команди:
`Провести і закрити | Записати | Провести | Скасувати проведення | Скопіювати (F9) | Закрити`.
Таблична частина «Ціни» — Interactive Grid.

## БЛОК C. БІЗНЕС-ЛОГІКА

Проведення: для кожного рядка запис `RegProductPrice(period = occurredAt,
priceType = шапка, product, price)`. Ціна діє з дати документа до наступного
встановлення. Без рядків документ не проводиться.
