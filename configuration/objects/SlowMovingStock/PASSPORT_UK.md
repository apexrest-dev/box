# Паспорт звіту «Неліквіди й залежалі товари»

## 0. Стан паспорта

- Статус: `PROPOSED` — підготовлено 2026-11-08, потребує явного погодження користувачем
  для переведення в `AGREED` (реалізовано за загальним дорученням користувача, APE-117).
- Ревізія: `r5`.
- Розділ меню (Taxi): `Склад`, `Продажі`, `Закупівлі`, `Головне` → «Звіти»; список «Звіти».
- Залежності: `RegStockCost` (кількість, вартість, організація), `RegSales` (останній продаж), `RegStockBalance` +
  `RefProductSeries` (терміни придатності, APE-63), звіт «Оборотність запасів» (`trade_turnover`, APE-116),
  `RegMarkdownRule`, `RegProductPrice` / `DocPriceSetting`, `RefProduct`, `RefProductGroup`, `RefWarehouse`,
  `RefOrganization`; «Картка товару» (сторінка 450).
- Аналог у 1С:УТ 11: звіти «Анализ неликвидных товаров» / «Залежавшиеся товары» (Запасы → Отчеты по запасам) і
  документ «Установка цен номенклатуры» для уцінки.
- Функції каталогу: `F-WH-25`.

Параметри:

| Параметр | Значення | Правила |
|---|---|---|
| На дату | дата залишку | типово сьогодні |
| Днів | поріг «залежалий» | порожньо — найменший поріг правил уцінки; ≤ 0 — помилка |
| Ознака | Без продажу / Без руху | `SALE` / `MOVE`; невідома — помилка |
| Показати | Лише залежалі й з терміном, що минає / Усі залишки | `Y` / `N` |
| Організація, Склад, Група номенклатури | відбір або усі | група — з підгрупами |
| Вид цін | `RefPriceType` | типово перший активний за кодом (роздрібна) |

Колонки рядка (товар × склад із залишком > 0): залишок і вартість, собівартість одиниці, перше й останнє надходження,
останній продаж, останнє вибуття, днів без продажу / руху, ознака «залежалий», вартість за віком партій (≤30, 31–90,
91–180, 181–365, >365 днів), найстаріша партія, продано й оборотність у днях за останні N днів, прострочено / спливає
(кількість серій), найближчий термін, правило, уцінка %, рекомендація, ціна, рекомендована ціна, «нижче собівартості».

## БЛОК B. ЛОГІКА (`trade_slow_stock`, db/46)

- Залишок і вартість — `RegStockCost` на кінець дати (послуги не входять); відбір за організацією узгоджений із
  «Оборотністю запасів».
- Днів без продажу = дата − останній продаж (рядки `RegSales` з кількістю > 0); не продавався — від першого надходження.
  Днів без руху = дата − max(останнє надходження, останнє вибуття). Залежалий — днів ≥ N.
- Вік партій — FIFO: залишок складають останні надходження; вартість групи = кількість × середня собівартість,
  нерозподілений залишок — у найстаршу групу.
- Заморожений капітал = вартість залишку залежалих позицій; також частка від усього залишку й вартість прострочених серій.
- Оборотність — `trade_turnover.analysis('PRODUCT_WAREHOUSE', дата − N + 1, дата, …)`.
- Серії: залишок `RegStockBalance` за серіями на дату; термін минув — «Списати прострочене»; спливає протягом N днів —
  «Уцінити: спливає термін» з уцінкою першого правила (якщо інша рекомендація не сильніша).
- Рекомендація за `RegMarkdownRule`; рекомендована ціна = ціна виду цін на дату × (1 − уцінка / 100).
- Порядок: залежалі зверху, далі за днями (спадання) і вартістю.
- `create_price_setting` — документ «Встановлення цін» (`DRAFT`) з рядками рекомендацій «уцінити / розпродати / спливає
  термін / прострочене» з рекомендованою ціною нижче поточної; ціна товару — найменша серед складів; аудит
  `CREATE_BASED_ON`; немає рядків — помилка «Немає товарів для уцінки». Після створення — перехід у документ (сторінка 101).

|---|---|
| Джерело залишку — `RegStockCost` | має організацію та вартість; серії — з `RegStockBalance` (без організації) |
