# Паспорт довідника «Каси»

## 0. Стан паспорта

- Статус: `PROPOSED` — підготовлено 2026-11-08 (Linear APE-51), реалізовано без формального
  погодження (як r2–r4); потребує явного погодження користувача.
- Ревізія: `r4`.
- Розділ основного меню: `Довідники`; панель функцій `Фінанси` (група «Казначейство») і
  `НСІ та адміністрування` (група «Підприємство»).
- Залежності: `RefOrganization`.
- Використовуватимуть: `DocCashReceipt` / `DocCashPayment` (ПКО/ВКО), регістр `RegCashBalance` (F-FIN-02…).
- Аналог у 1С:УТ 11: Справочник.Кассы (власник — організація, валюта, касир).
- Функція каталогу: `F-FIN-01` (каси й банківські рахунки).

## БЛОК A. СТРУКТУРА

### 1. Ідентичність і призначення

| Параметр | Значення |
|---|---|
| Українська назва | Каси |
| Технічне ім'я | `RefCashDesk` |
| Технічний ключ | `Catalog.CashDesk` |
| Доменний клас / ID-клас | `CashDesk` / `CashDeskId` |
| Таблиця | `ref_cash_desk` (представлення списку `v_cash_desk`) |
| API | `/api/v1/catalogs/cash-desks` |
| Сторінки APEX | 340 (список), 341 (елемент, модальний діалог) |

Простий неієрархічний довідник місць зберігання готівки організації. Код текстовий,
9 символів, автоматичний (`ref_cash_desk_code_seq`) з можливістю ручної зміни. Вид
видалення — `MARK_FOR_DELETION`.

### 2. Поля

| Поле | Назва | Тип | Розмір | Обов'язкове | Правило |
|---|---|---|---|---|---|
| `id` | ID | UUID | — | так | PK |
| `code` | Код | String | 9 | так | UNIQUE, автоматичний |
| `name` | Найменування | String | 255 | так | trim, 1–255 |
| `organizationId` | Організація | `RefOrganization` | — | так | активна; порожнє → організація за замовчуванням |
| `currencyCode` | Валюта | String | 3 | так | ISO 4217, 3 латинські літери, верхній регістр; за замовчуванням `UAH` |
| `responsibleName` | Відповідальний (касир) | String | 255 | ні | ПІБ для підпису в касових ордерах |
| `note` | Коментар | String | 1000 | ні | — |
| `state`, `version`, аудит | — | — | — | так | як у всіх довідниках |

### 3. Ієрархія і дочірні структури

Немає.

### 4. Стани, інваріанти та команди

- Стани `ACTIVE`, `MARKED_FOR_DELETION`; фізичне видалення заборонене.
- Касу не можна створити або перенести в організацію, помічену на видалення.
- Команди: `CreateCashDesk`, `UpdateCashDesk`, `MarkCashDeskForDeletion`, `RestoreCashDesk`.
