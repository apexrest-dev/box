# Паспорт довідника «Банківські рахунки»

## 0. Стан паспорта

- Статус: `PROPOSED` — підготовлено 2026-11-08 (Linear APE-51), реалізовано без формального
  погодження (як r2–r4); потребує явного погодження користувача.
- Ревізія: `r4`.
- Розділ основного меню: `Довідники`; панель функцій `Фінанси` (група «Казначейство») і
  `НСІ та адміністрування` (група «Підприємство»).
- Залежності: `RefOrganization` (власник рахунку).
- Використовуватимуть: `DocBankStatement`, безготівкові оплати, `RegCashBalance`, друк рахунку
  на оплату (основний рахунок організації).
- Аналог у 1С:УТ 11: Справочник.БанковскиеСчетаОрганизаций (номер рахунку IBAN, банк, валюта,
  власник; «Основний банківський рахунок» організації).
- Функція каталогу: `F-FIN-01` (каси й банківські рахунки).

## БЛОК A. СТРУКТУРА

### 1. Ідентичність і призначення

| Параметр | Значення |
|---|---|
| Українська назва | Банківські рахунки |
| Технічне ім'я | `RefBankAccount` |
| Технічний ключ | `Catalog.BankAccount` |
| Доменний клас / ID-клас | `BankAccount` / `BankAccountId` |
| Таблиця | `ref_bank_account` (представлення списку `v_bank_account`) |
| API | `/api/v1/catalogs/bank-accounts` |
| Сторінки APEX | 350 (список), 351 (елемент, модальний діалог) |

Довідник безготівкових рахунків власних організацій. Код текстовий, 9 символів,
автоматичний (`ref_bank_account_code_seq`). Вид видалення — `MARK_FOR_DELETION`.

### 2. Поля

| Поле | Назва | Тип | Розмір | Обов'язкове | Правило |
|---|---|---|---|---|---|
| `id` | ID | UUID | — | так | PK |
| `code` | Код | String | 9 | так | UNIQUE, автоматичний |
| `name` | Найменування | String | 255 | так | порожнє → «<банк>, <валюта> …<4 останні цифри IBAN>» |
| `organizationId` | Організація (власник) | `RefOrganization` | — | так | активна; порожнє → за замовчуванням |
| `iban` | IBAN | String | 29 | так | UNIQUE; пробіли й дефіси прибираються, верхній регістр; `UA` + 27 цифр; контрольна сума ISO 13616 (mod 97 = 1) |
| `mfo` | МФО банку | String | 6 | так | = позиції 5–10 IBAN; порожнє заповнюється з IBAN, розбіжність — помилка |
| `bankName` | Банк | String | 255 | так | trim |
| `currencyCode` | Валюта | String | 3 | так | ISO 4217; за замовчуванням `UAH` |
| `isDefault` | Основний рахунок | Y/N | — | так | не більше одного на «організація + валюта» |
| `note` | Коментар | String | 1000 | ні | — |
| `state`, `version`, аудит | — | — | — | так | як у всіх довідниках |

### 3. Ієрархія і дочірні структури

Немає.

### 4. Стани, інваріанти та команди

- Стани `ACTIVE`, `MARKED_FOR_DELETION`; фізичне видалення заборонене.
- Коди помилок: `BANK_ACCOUNT_IBAN_REQUIRED`, `BANK_ACCOUNT_IBAN_FORMAT`,
  `BANK_ACCOUNT_IBAN_CHECKSUM`, `BANK_ACCOUNT_MFO`, `CURRENCY_CODE`; дубль IBAN —
  обмеження `ref_bank_account_iban_uk` («Банківський рахунок з таким IBAN уже існує»).
- Встановлення ознаки «Основний» знімає її з інших рахунків тієї ж організації й валюти
  (компаунд-тригер, одна транзакція). Помічений на видалення рахунок перестає бути основним.
- `trade_fin.default_bank_account(org, currency)` — основний активний рахунок, інакше перший за кодом.
- Рахунок не можна створити або перенести в організацію, помічену на видалення.
- Команди: `CreateBankAccount`, `UpdateBankAccount`, `MarkBankAccountForDeletion`, `RestoreBankAccount`.
