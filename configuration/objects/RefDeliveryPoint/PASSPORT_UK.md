# Паспорт довідника «Точки доставки (GLN)»

## 0. Стан паспорта

- Статус: `PROPOSED` — підготовлено 2026-11-08, потребує явного погодження користувачем
  для переведення в `AGREED` (реалізовано за загальним дорученням користувача, APE-118).
- Ревізія: `r7`.
- Розділ меню (Taxi): `Продажі` → «EDI», «НСІ»; список «Довідники».
- Залежності: `RefCounterparty` (мережа-покупець), `RefWarehouse`, `RefPriceType`.
- Аналог у 1С:УТ 11: адреси доставки / «Партнери → Торгові точки» з GLN для обміну EDI (спрощено: без графіка
  доставки й зон доставки).
- Функції каталогу: `F-INT-04`.

Поруч (db/47): `ref_organization.gln` (GLN постачальника), `ref_counterparty.gln` (GLN мережі-покупця) — необов'язкові,
унікальні, з тією самою перевіркою; `doc_customer_order.delivery_point_id` (точка доставки має належати покупцю
замовлення — `DELIVERY_POINT_CUSTOMER`), `ext_order_number`, `ext_order_date` (№ і дата замовлення мережі).

## БЛОК B. ЛОГІКА

Тригер `ref_delivery_point_biu` → `trade_edi.check_delivery_point`; `ref_organization_gln_biu`, `ref_counterparty_gln_biu`,
`doc_customer_order_edi_biu`. Помічену точку не зіставляє вхідне повідомлення й не можна вибрати в замовленні. Журнал
реєстрації — `ref_delivery_point_evlog` (db/37), помітка на видалення — `trade_core.catalog_table` (db/02).
