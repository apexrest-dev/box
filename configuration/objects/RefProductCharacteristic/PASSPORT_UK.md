# Паспорт довідника «Характеристики номенклатури»

## 0. Стан паспорта

- Статус: `PROPOSED` — підготовлено 2026-11-08, потребує явного погодження користувачем
  для переведення в `AGREED` (реалізовано за загальним дорученням користувача, APE-63).
- Ревізія: `r5`.
- Розділ меню (Taxi): `НСІ` → група «Номенклатура».
- Залежності: `RefProduct` r5 (ознака `useCharacteristics`), `RegStockBalance`,
  `RegStockReserve`, `RegStockCost` (вимір `characteristicId`).
- Аналог у 1С:УТ 11: Справочник.ХарактеристикиНоменклатуры (спрощено: характеристики
  підпорядковані конкретному товару, без видів номенклатури, наборів додаткових реквізитів
  і генерації характеристик за значеннями властивостей).
- Функції каталогу: `F-NSI-10`.

## БЛОК A. СТРУКТУРА

### 1. Ідентичність і призначення

| Параметр | Значення |
|---|---|
| Українська назва | Характеристика номенклатури (список — «Характеристики номенклатури») |
| Технічне ім'я | `RefProductCharacteristic` |
| Таблиця | `ref_product_characteristic` |
| Сторінки APEX | 490 — список, 491 — картка (модальний діалог) |
| Код | `ref_product_characteristic_code_seq`, 9 цифр; ручний код 1–9 символів |
| Видалення | лише помітка на видалення (`state = MARKED_FOR_DELETION`) |
| Права | перегляд — усі ролі; запис — «Роль: склад або закупівлі» (і адміністратор) |

Характеристика — варіант виконання товару (розмір, колір, комплектація), у розрізі якого
ведуться складські залишки. Використовується лише для товарів з ознакою
«Використовувати характеристики».

## БЛОК B. ЛОГІКА

- Рядки документів (`characteristic_id`): характеристика має належати товару рядка
  (`CHARACTERISTIC_OTHER_PRODUCT`), не бути поміченою на видалення (`CHARACTERISTIC_NOT_ACTIVE`);
  для товару без ознаки значення очищається.
- Проведення: для товару з ознакою рух `RegStockBalance` без характеристики заборонено
  (`CHARACTERISTIC_REQUIRED`); видатковий рух контролює залишок ключа
  склад × товар × характеристика (× серія) — `INSUFFICIENT_SERIES_STOCK`.
- Реалізація на підставі замовлення клієнта бере характеристику з рядка замовлення, якщо вона
  однозначна для товару; «Скопіювати» переносить характеристики рядків.
