# Паспорт довідника «Специфікації наборів»

## 0. Стан паспорта

- Статус: `PROPOSED` — підготовлено 2026-11-08, потребує явного погодження користувачем
  для переведення в `AGREED` (реалізовано за загальним дорученням користувача, APE-58).
- Ревізія: `r4`.
- Розділ меню (Taxi): `Склад` → група «НСІ»; `НСІ` → група «Номенклатура».
- Залежності: `RefProduct` r3 (`productKind = GOODS`), `RefUnitOfMeasure` (дробність),
  `RegStockCost` (орієнтовна собівартість набору).
- Аналог у 1С:УТ 11: Справочник.ВариантыКомплектацииНоменклатуры (спрощено: без
  характеристик, без послуг у складі набору, без типу комплектації «при продажу»).
- Функції каталогу: `F-WH-10` (основна).

## БЛОК A. СТРУКТУРА

### 1. Ідентичність і призначення

| Параметр | Значення |
|---|---|
| Українська назва | Специфікація набору (список — «Специфікації наборів») |
| Технічне ім'я | `RefBillOfMaterials` |
| Таблиці | `ref_bill_of_materials`, `ref_bill_of_materials_items` |
| Сторінки APEX | 430 — список, 431 — картка (модальний діалог з табличною частиною) |
| Код | `ref_bill_of_materials_code_seq`, 9 цифр; ручний код 1–9 символів |
| Видалення | лише помітка на видалення (`state = MARKED_FOR_DELETION`) |
| Права | перегляд — усі ролі; запис — «Роль: склад» (і адміністратор) |

Специфікація задає склад набору (комплекту): які товари й у якій кількості потрібні на
`quantity` наборів. Використовується документом «Комплектація товарів» (`DocAssembly`)
для заповнення комплектуючих і як база розподілу собівартості при розкомплектації.
Набір може мати кілька специфікацій (варіантів), одна з них — основна.

| Поле | Назва | Тип | Обов'язкове | Правила |

## БЛОК B. ЛОГІКА

- `trade_assembly.main_bom(productId)` — основна, інакше перша активна специфікація набору
  (за кодом); підставляється в нову комплектацію.
- `trade_assembly.bom_cost(bomId, warehouseId)` — орієнтовна собівартість одного набору:
  Σ (`lastAverageCost` комплектуючої × кількість / кількість набору); null, якщо для
  якоїсь комплектуючої немає даних.
- Помилки: `PRODUCT_SERVICE_NOT_ALLOWED`, `BOM_KIT_IN_COMPONENTS`, `BOM_EMPTY` (заповнення
  документа за порожньою специфікацією), фізичне видалення заборонене.
