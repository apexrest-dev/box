# ADR-0001: Платформа та модульна структура

- Статус: прийнято
- Дата: 2026-09-01

## Контекст

Потрібен один підтримуваний каркас сервера, клієнта й спільних типів із чіткою межею бізнес-логіки.

## Рішення

Використовуємо Java 21, Maven, Spring Boot 4.1.1 і JavaFX 21. Основний застосунок є модульним монолітом із модулями `domain-core`, `shared-contracts`, `server`, `ui-library`, `client`. Конфігуратор залишається окремим design-time застосунком.

## Наслідки

Домен не залежить від Spring/JavaFX/JDBC. Розподілена система й мікросервіси не вводяться. Оновлення версій виконується централізовано в кореневому `pom.xml`.
