# ADR-0002: Дві СУБД і міграції

- Статус: прийнято
- Дата: 2026-09-01

## Контекст

Trade має працювати локально на SQLite й у мережі на PostgreSQL без двох різних бізнес-моделей.

## Рішення

Тип СУБД обирається Spring-профілем. Схема змінюється Flyway-міграціями. Спільний переносний SQL зберігається в `db/migration/common`; специфічний SQL дозволений лише в ізольованих infrastructure-адаптерах із еквівалентною поведінкою.

Для першого каркаса використовується Spring JDBC за application-портами. Вибір JPA для конкретних агрегатів потребуватиме окремого рішення після появи першого паспорта.

## Наслідки

Кожна persistence-зміна перевіряється на SQLite й справжньому PostgreSQL. PostgreSQL-тести використовують Testcontainers і пропускаються лише коли Docker недоступний.
