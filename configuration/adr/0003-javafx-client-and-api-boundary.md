# ADR-0003: JavaFX-клієнт і межа API

- Статус: прийнято
- Дата: 2026-09-01

## Контекст

Потрібна стандартна бібліотека полів і форм без дублювання серверних правил та без автогенерованих форм.

## Рішення

JavaFX-форми описуються Java-кодом, без FXML. Клієнт використовує `ui-library`, надсилає типізовані команди через версіонований REST API та відображає підтверджений сервером стан. Прямий JDBC, формули, права й проведення у клієнті заборонені.

## Наслідки

UI-контроли можуть виконувати форматування та зручну попередню валідацію, але сервер повторно перевіряє всі дані. Клієнт і сервер зв'язані лише стабільними DTO з `shared-contracts`.
